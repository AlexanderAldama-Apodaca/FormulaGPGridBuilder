The FormulaGPGridBuilder project is intended to enable players of the board game FormulaGP to simulate real Formula One seasons.

FormulaGPGridBuilder.py allows players to generate random opponents for games of FormulaGP.

FormulaGPGridBuilderV2.py allows players to generate random opponents for games of FormulaGP
with altered probabilities based on driver nationality, team nationality, and car speed

The program can be run in Visual Studio Code or any platform that can run Python code and has access to a terminal.
